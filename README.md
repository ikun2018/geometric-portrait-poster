# Geometric Portrait Poster

A Codex skill for creating crisp, high-contrast geometric portrait posters from an uploaded portrait or a text description.

It uses deliberate flat polygon facets and offers five palette presets: neon violet/blue, warm retro, teal/orange, monochrome editorial, and colors sampled from the source image.

## Install

Copy this folder to `$CODEX_HOME/skills/geometric-portrait-poster` (usually `~/.codex/skills/geometric-portrait-poster`), then start a new Codex task and ask for a geometric portrait poster. Choose a palette when prompted.

## Contents

- `SKILL.md` — generation workflow and prompt guidance
- `references/palettes.md` — palette presets
- `agents/openai.yaml` — skill display metadata
- `assets/icon.svg` — skill icon
